# CMS Canva 이미지 용량 산출 근거

집계일: 2026.09.23. 문서 작성일: 2026.09.29. 이 수치는 9월 23일 이 작업에서 읽은 CMS 파일의 집계 결과이며, 9월 29일에 재측정한 값이 아닙니다.

대상은 `C:\workspace\codmos-cms\contents\canva_*\public`의 비어 있지 않은 10개 폴더와 208개 HTML입니다. 빈 `canva_test`, 개발 의존성, 빌드 캐시와 `.output`은 제외했습니다.

## 이력서에 사용할 문장

Canva 이미지에 MD5 기반 중복 제거·WebP 변환을 적용했습니다. 10개 폴더·208개 HTML의 참조 이미지 기준, 같은 형식으로 페이지마다 저장하는 가정 대비 용량을 약 62.8% 절감한 것으로 추산했습니다(1,128.21 → 419.41 MiB, 2026.09.23 집계).

## 계산 기준

- 실제 파일 크기는 각 파일의 바이트 수로 집계했습니다. 1 MiB는 1,048,576바이트입니다.
- HTML에서 12자리 16진수 해시 파일명과 이미지 확장자(WebP·PNG·JPEG·SVG·GIF·BMP·TIFF)를 찾고, 각 HTML 안에서 같은 파일명은 한 번만 계산했습니다.
- 비교 가정은 각 HTML이 참조하는 이미지를 페이지별로 따로 저장하는 경우입니다. 여러 HTML이 같은 이미지를 참조하면 그 파일 크기를 페이지마다 더했습니다.
- 고유 이미지 용량은 같은 폴더의 HTML 전체가 참조하는 파일명을 합쳐 중복을 제거한 값입니다. 서로 다른 콘텐츠 폴더 사이의 중복은 합치지 않았습니다.
- 참조 여부는 HTML에 등장하는 파일명으로 판별했습니다. 실행 중 동적으로 구성되는 참조를 브라우저에서 검증한 결과는 아닙니다.

| 항목 | 값 |
| --- | ---: |
| 현재 `public/` 전체 파일 | 501.28 MiB |
| 현재 저장된 해시 이름 이미지 전체 | 433.78 MiB |
| HTML에서 참조된 고유 이미지 | 419.41 MiB |
| 같은 형식의 페이지별 중복 저장 가정 | 1,128.21 MiB |
| 비교 가정 대비 차이 | 708.80 MiB / 약 62.8% |

절감률은 `(1,183,018,588 - 439,786,647) / 1,183,018,588 × 100`으로 계산했습니다. 전체 용량을 합산한 비율이며, 폴더별 절감률의 단순 평균이 아닙니다.

현재 저장된 이미지 중 14.37 MiB는 이 HTML 파일명 검사에서 참조가 확인되지 않아, 양쪽 참조 이미지 비교에서 제외했습니다. 따라서 419.41 MiB를 현재 폴더 전체 크기라고 표현하면 안 됩니다.

## 해석의 한계

이 비교는 현재 저장된 파일 형식을 유지한 중복 저장 가정입니다. WebP 변환 전 원본 바이트 크기와 원본 URL별 다운로드 이력이 없어, 압축과 중복 제거를 모두 적용하기 전의 실제 용량은 복원하지 못했습니다. 같은 HTML 안에서 서로 다른 원본 URL이 동일한 해시로 합쳐진 효과도 이 비교로 분리할 수 없습니다.

따라서 “원본 대비 62.8% 실측 감소”, “모든 폴더에서 60% 이상 감소”, “로딩 속도 62.8% 개선”, “CDN 비용 62.8% 절감”으로 확대해서 쓰지 않습니다.

구현 근거는 `C:\workspace\codmos-cms\scripts\process-canva.mjs`입니다. 조사 당시 다운로드한 바이트의 MD5 앞 12자리를 파일명에 사용하고, 래스터에 `sharp(...).webp({ quality: 85 })`를 적용했습니다. SVG·GIF는 유지하며 변환 실패 시 원본을 저장하는 경로가 있습니다.
